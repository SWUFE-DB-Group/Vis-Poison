# COCO Images

This directory should contain the MS COCO JPEG images referenced by `dataset/COCO/coco_random_1k.json`.

The JSON records use COCO image IDs and filenames such as `000000040065.jpg`. The images are natural COCO scenes with everyday objects, people, animals, vehicles, indoor rooms, and outdoor environments. For example, the first sample caption is `Six vintage luggages stacked on top of each other.` and points to `000000040065.jpg`.

Images are intentionally not committed. Copy the corresponding COCO image files here before building image-based FAISS indexes.
