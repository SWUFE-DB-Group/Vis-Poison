# Flickr30k Images

This directory should contain the Flickr30k JPEG images referenced by `dataset/Flickr30k/flickr30k_random_1k.json`.

The JSON records use image filenames such as `3156991513.jpg`. The images are natural Flickr30k photos of people, actions, objects, and everyday scenes. For example, the first sample caption is `A man is riding a bicycle on a dirt path.` and points to `3156991513.jpg`.

Images are intentionally not committed. Copy the corresponding Flickr30k image files here before building image-based FAISS indexes.
